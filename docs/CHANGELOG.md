# 版本变更记录

本项目采用 `vX.Y.Z` 标签发布桌面安装包。重大行为变化会在对应版本说明中记录；配置与任务数据 schema 的兼容边界以 [配置与使用](CONFIGURATION.md) 为准。

## 0.9.0

- 设置页支持显式配置 Meegle CLI 可执行路径；未配置时会通过平台 login shell 自动探测并缓存结果，探测失败仍回退到原有 PATH 命令。
- macOS 的开发工具选择器支持选择 `.app` 应用包。
- 新增任务说明模板库；创建任务时可选择模板填充人工说明，切换模板时会保护已经手工修改的内容。
- 修复任务说明模板编辑对话框内容较长时保存按钮被挤出可视区域的问题。
- 配置和任务清单 schema 升至严格的 `0.9.0`；0.8.x 数据不会读取或迁移。

## 0.8.1

- 服务配置弹窗改为左侧分组导航（基本信息、工具与提交、工作区模块、Bootstrap），弹窗加宽以容纳分组内容。
- 任务详情新增 AGENTS.md 预览按钮，预览与保存同源渲染；主页侧边栏头部精简为图标与 AWM。
- 任务详情头部的“有警告”“已归档”状态前移到需求状态之后；需求标题读取失败时可点击重试图标强制刷新。
- 批量 Tag 与批量 Commit、Commit & Push、Push 弹窗默认不选中任何工作区，并提供“全选”“全不选”快捷操作。
- Tag 构建成功的复制文本调整为先需求链接与发版提示、再列出版本清单。
- 桌面 UI 文件按界面职责拆分；配置和任务清单 schema 升至 `0.8.1`，兼容读取 0.8.0 数据。

## 0.8.0

- 工作区策略下沉到模块级，同一服务可混合配置标准 Worktree 与独立克隆。
- 创建任务、追加服务及任务详情支持动态增删模块；模块策略、分支和 Tag 行为写入任务快照。
- 克隆模块支持直接检出基础分支、从基础分支新建目标分支，以及确认复用已有远程目标分支。
- 模块删除增加远程刷新、差异检查、风险确认和可恢复备份事务。
- Git 设置增加分支写保护，默认阻止在 `master`、`main` 上提交、推送和需要写入分支的 Tag 流程。
- 配置和任务清单 schema 升至严格的 `0.8.0`，不读取或迁移 0.7.x 数据。

## 0.7.0

- 标准 Worktree 多模块改为每模块一个独立物理 Worktree；创建与追加服务支持分别搜索、编辑基础分支和目标分支，并保留用户手工目标分支。
- 新增任务详情分支隐藏规则与本地只读 Git 信息面板；远程 URL 原样展示，Git 面板不会执行联网命令。
- 临时 IDE 选择改为默认关闭的全局开关；移除错误的“创建任务后自动打开服务”行为。
- 修复高 DPI 下窗口仍可缩得过窄、工作区操作换行、需求信息间距、Git 图标及服务校验错误被压在底部等问题。
- 点击任务会按任务清单校验每个 Git 工作区，区分目录缺失、Git 失效、仓库身份错误、错误分支和进行中操作，并提供带预检、远程复用确认、备份及回滚的一键修复。
- 创建任务的分支输入支持搜索所选服务的远程分支；Bootstrap 选择复制源时会联动填充尚未手工修改的目标路径。
- 任务详情完整展示分支和需求标题，顶部与工作区行使用图标工具组，并支持对全部物理工作区批量 Commit、Commit & Push、Push。
- Tag 支持“合并到目标分支”和“当前分支直接构建”两种模式，产品配置与界面统一移除 UAT 命名。
- 服务弹窗自适应扩宽，单分组允许重命名；Bootstrap 初始化命令不再配置平台过滤。
- 增加六种由用户手工选择路径的开发工具，并支持服务默认工具和临时切换。
- 设置页改为“配置项目 + 当前详情”两栏，飞书项目与日志分别管理。
- Bootstrap 增加表单与高级 JSON 双模式，并覆盖 Worktree、独立克隆创建与恢复。
- 创建任务和追加服务支持逐模块覆盖基础分支；普通远程刷新不再同步 Tag。
- 任务详情增加 Commit、Push、Commit & Push；远程缺少同名分支时创建 upstream，禁止强制推送。
- 移除原仓库分支策略；包含该策略的旧配置和任务清单会明确拒绝读取并保留磁盘数据。
- 配置和任务清单 schema 升至严格的 `0.7.0`，不读取或迁移 0.6.x 数据。

## 0.6.0

- 创建任务和追加服务会在创建目录前扫描本地、远程及已被 Worktree 检出的分支；确认后可复用已有分支，已检出的分支必须额外确认共享分支风险。
- 远程已有分支会创建本地跟踪 Worktree；本地已有分支保留既有 upstream；已占用分支使用强制附加。
- 工作区清单记录分支创建归属和强制附加状态，失败回滚不会删除预先存在的分支或 Worktree。
- 配置和任务清单 schema 升至严格的 `0.6.0`，不读取或迁移 0.5.x 数据。

## 0.5.3

- 修复 AGENTS.md Markdown 预览在部分窗口宽度、系统缩放或宽表格内容下因嵌套横向滚动而崩溃的问题。

## 0.5.2

- 修复任务列表选中卡片出现内外两层不同蓝灰背景的问题，统一整卡选中颜色与圆角点击区域。

## 0.5.1

- 异步创建、服务配置、添加仓库和批量 Tag 操作仅在真实成功后关闭弹窗，失败时保留用户草稿。
- 修复活跃/归档导航的空详情状态，并为创建任务和服务配置增加未保存修改确认。
- 设置页增加固定分区导航并记忆上次位置；应用记忆窗口尺寸和最大化状态。
- 补充删除组/移除服务确认、图标操作提示，以及可滚动、可选择文本的 Tag 结果展示。

## 0.5.0

- 将任务生命周期 `ACTIVE / ARCHIVED` 与工作区健康 `CREATING / READY / READY_WITH_WARNINGS / FAILED` 分离，归档不再改变或限制工作区能力。
- 配置和任务清单升级为字符串 schema `0.5.0`；兼容同一 `0.5.x` PATCH，严格拒绝 0.4.x 和非法版本格式。
- 桌面 UI 按任务、服务设置、创建任务和共享对话框拆分；Controller 使用不可变 `UiState` 与注入动作，不再反向持有整个应用容器。
- 飞书状态增加同键请求去重、5 分钟成功缓存、30 秒失败退避、最多 4 个并发请求和过期结果丢弃；失败只显示中性状态。

## 0.4.2

- 归档任务仅用于分类并保留全部工作区操作；删除任务始终保留远程分支。
- 服务仓库改为组标签页，任务列表展示飞书需求状态。

## 0.4.1

- 修复任务信息、Tag 结果和归档导航交互，并统一可读工作区目录命名与版本规则。

## 0.4.0

- 标准 Worktree 与独立克隆都支持多个模块；独立克隆按每个模块的固定远程分支创建独立目录；
- Tag 改为统一的组级和模块级开关，独立克隆模块拥有自己的目标分支与 Tag 配置；
- 配置和任务清单 schema 统一为严格字符串版本 `"0.4.0"`，不读取或迁移旧格式；
- 所有已有远程分支输入统一支持按远程加载、搜索和选择，仍可手工输入合法引用。

## 0.3.0

- 产品更名为 Agent Workspace Manager（AWM），定位为任务级 Agent 开发工作区编排器；
- 移除 CLI，仅保留 `core` 与 `desktop`；
- 引入组、服务、模块、标准 Worktree 与独立克隆策略；
- 增加三级 `AGENTS.md` 合成、磁盘同步和冲突保护；
- 增加任务 Git 健康状态：未提交文件、未推送提交和工作区风险；
- 支持飞书 Meegle 需求链接、`{num}` 分支前缀和需求标题自动填写；
- 将 Tag 封装为交付流水线适配器，并保留安全预检和历史；
- 支持通过适配器打开 Codex 和 Cursor 工作区；
- 配置 schema 升级为 v7，任务 schema 升级为 v5；旧 TaskWT 数据不会读取、迁移或删除。

## 0.2.0

- 引入组、服务工作区与任务级 Agent 说明的基础能力；
- 发布 Windows portable ZIP、EXE、MSI 和 macOS DMG 流程。

## 0.1.4

- Task Worktree Manager 的最后一个公开早期版本。
