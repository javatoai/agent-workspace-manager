# 版本变更记录

本项目采用 `vX.Y.Z` 标签发布桌面安装包。重大行为变化会在对应版本说明中记录；配置与任务数据 schema 的兼容边界以 [配置与使用](CONFIGURATION.md) 为准。

## 0.6.0

- 创建任务和追加服务会在创建目录前扫描本地、远程及已被 Worktree 检出的分支；确认后可复用已有分支，已检出的分支必须额外确认共享分支风险。
- 远程已有分支会创建本地跟踪 Worktree；本地已有分支保留既有 upstream；已占用分支使用强制附加。
- 工作区清单记录分支创建归属和强制附加状态，失败回滚不会删除预先存在的分支或 Worktree。
- 配置和任务清单 schema 升至严格的 `0.6.0`，不读取或迁移 0.5.x 数据。

## 0.5.3

- 修复 AGENTS.md Markdown 预览在部分窗口宽度、系统缩放或宽表格内容下因嵌套横向滚动而崩溃的问题。

## 0.5.2

- 修复任务列表选中卡片出现内外两层不同蓝灰背景的问题，统一整卡选中颜色与圆角点击区域。

## 0.5.1

- 异步创建、服务配置、添加仓库和批量 UAT 操作仅在真实成功后关闭弹窗，失败时保留用户草稿。
- 修复活跃/归档导航的空详情状态，并为创建任务和服务配置增加未保存修改确认。
- 设置页增加固定分区导航并记忆上次位置；应用记忆窗口尺寸和最大化状态。
- 补充删除组/移除服务确认、图标操作提示，以及可滚动、可选择文本的 UAT 结果展示。

## 0.5.0

- 将任务生命周期 `ACTIVE / ARCHIVED` 与工作区健康 `CREATING / READY / READY_WITH_WARNINGS / FAILED` 分离，归档不再改变或限制工作区能力。
- 配置和任务清单升级为字符串 schema `0.5.0`；兼容同一 `0.5.x` PATCH，严格拒绝 0.4.x 和非法版本格式。
- 桌面 UI 按任务、服务设置、创建任务和共享对话框拆分；Controller 使用不可变 `UiState` 与注入动作，不再反向持有整个应用容器。
- 飞书状态增加同键请求去重、5 分钟成功缓存、30 秒失败退避、最多 4 个并发请求和过期结果丢弃；失败只显示中性状态。

## 0.4.2

- 归档任务仅用于分类并保留全部工作区操作；删除任务始终保留远程分支。
- 服务仓库改为组标签页，任务列表展示飞书需求状态。

## 0.4.1

- 修复任务信息、UAT 结果和归档导航交互，并统一可读工作区目录命名与版本规则。

## 0.4.0

- 标准 Worktree 与独立克隆都支持多个模块；独立克隆按每个模块的固定远程分支创建独立目录；
- UAT Tag 改为统一的组级和模块级开关，独立克隆模块拥有自己的目标分支与 Tag 配置；
- 配置和任务清单 schema 统一为严格字符串版本 `"0.4.0"`，不读取或迁移旧格式；
- 所有已有远程分支输入统一支持按远程加载、搜索和选择，仍可手工输入合法引用。

## 0.3.0

- 产品更名为 Agent Workspace Manager（AWM），定位为任务级 Agent 开发工作区编排器；
- 移除 CLI，仅保留 `core` 与 `desktop`；
- 引入组、服务、模块、标准 Worktree 与独立克隆策略；
- 增加三级 `AGENTS.md` 合成、磁盘同步和冲突保护；
- 增加任务 Git 健康状态：未提交文件、未推送提交和工作区风险；
- 支持飞书 Meegle 需求链接、`{num}` 分支前缀和需求标题自动填写；
- 将 UAT Tag 封装为交付流水线适配器，并保留安全预检和历史；
- 支持通过适配器打开 Codex 和 Cursor 工作区；
- 配置 schema 升级为 v7，任务 schema 升级为 v5；旧 TaskWT 数据不会读取、迁移或删除。

## 0.2.0

- 引入组、服务工作区与任务级 Agent 说明的基础能力；
- 发布 Windows portable ZIP、EXE、MSI 和 macOS DMG 流程。

## 0.1.4

- Task Worktree Manager 的最后一个公开早期版本。
